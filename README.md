# TankGame

C++ と [OpenSiv3D](https://siv3d.github.io/ja-jp/) で作る、2D 見下ろし型の戦車ゲームです。

## 目的

C++ の学習を兼ねた個人開発です。ゲームを段階的に作りながら、クラス設計・コンテナ・所有権などの C++ の基礎と、Siv3D の使い方を身につけることを目指しています。

## 現状

**Stage 8 まで実装済み**：タイトル → 全 3 ステージ → リザルトまで遊べます。

- 壁で跳ね返る弾、テキストファイルで作るマップ
- 2 種類の敵 AI（巡回・追跡・捜索する戦車と、固定砲台）
- 残機制、HUD、爆発・効果音・画面の揺れなどの演出
- 射撃のばらつき（動きながら・連射すると弾が狙いからずれる）

| 操作 | 動き |
|---|---|
| `W` / `S` | 前進 / 後退 |
| `A` / `D` | 車体の回転 |
| マウス | 砲塔の向き |
| 左クリック | 発射 |
| `F2` | 敵 AI のデバッグ表示 |

今後は、独自要素（リプレイ、マップの自動生成、自作 AI など）を追加していく予定です。

## 開発環境

- Windows 11
- Visual Studio 2022 (17.14 以降)：「C++ によるデスクトップ開発」ワークロードが必要
- OpenSiv3D SDK v0.6.16：インストール時に設定される環境変数 `SIV3D_0_6_16` を参照してビルドします

## ビルドと実行

1. `TankGame.sln` を Visual Studio 2022 で開く
2. 構成を `Debug` / `x64` にする
3. `F5` で実行する
